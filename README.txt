JYLAN.OI v1.0

Запуск: откройте index.html в браузере.
Публикация: перетащите папку JYLAN_OI на https://app.netlify.com/drop либо загрузите ZIP после распаковки.
Управление: стрелки/WASD, свайпы, экранные кнопки. Пробел — пауза.
Рекорд хранится локально в браузере. Сервер и аккаунты не требуются.
Для установки PWA рекомендуется в будущем добавить PNG-иконки 192 и 512 пикселей в manifest.webmanifest.
